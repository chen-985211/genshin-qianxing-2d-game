# 原神·千星奇域二维小游戏开发

一个面向 Codex 的 Skill：AI 编写适配《原神》千星奇域的 Lua，人按逐步指导完成编辑器搭建、脚本挂载和试玩。

适用范围：单人、电脑键鼠、二维 UI 小游戏。包含概念图拆解与视觉还原、模板与宿主搭建、官方成功结算、动效音效接入，以及截图、日志和 `.gia` 排错流程。

仓库：[chen-985211/genshin-qianxing-2d-game](https://github.com/chen-985211/genshin-qianxing-2d-game) · 默认分支：`main`

**当前状态（2026-10-02）：**已创建私有 GitHub 仓库并推送代码。基础编辑器搭建流程由作者实机验证；整理成 Skill 后的独立新对话试用待完成。尚未公开发布，也尚未添加开源许可证。

## 使用前需要什么

- 能读取本地 Skill、生成文件并查阅官方开发资料的 Codex 环境。
- 可使用千星奇域编辑器及客户端脚本的游戏环境；相关权限按当前官方要求开通。
- 人能够操作编辑器、复制模板索引、粘贴代码并进行实机试玩。

Skill 提供流程和约束，具体游戏代码在使用时生成。游戏接口仍需 AI 按官方资料核对，最终效果由实机试玩确认。仓库不附带原神客户端、美术音频资源或 `.gia` 解析器；分析 `.gia` 需要可用且兼容的解析工具，无法可靠解析时应继续使用报错与节点截图定位。

## 先在自己电脑上试用

如果已经安装并能调用这个 Skill，无需重复安装。作者当前本地安装已指向维护仓库，修改仓库后，新对话可读取更新后的文件。

### 1. 用新对话验证完整流程

在用于生成游戏文件的目录中开启一个全新 Codex 对话，使用普通本地任务即可。不要从之前开发游戏的对话分叉，也不要把之前的代码和长聊天记录作为前提。这样才能检验 Skill 自身是否足以引导操作。

第一次完整试用建议使用独立测试关卡，从未搭建模板和结算的状态开始。发送：

```text
使用 $genshin-qianxing-2d-game。

我想在《原神》千星奇域里从零做一个二维打砖块小游戏：
鼠标左右移动挡板，小球反弹击碎砖块，球掉落扣生命。
画面明亮清晰，有碰撞和通关动画；先不添加声音资源。
需要重新开始，并在通关后可以选择完成游玩，进入官方成功结算。

请先读取 Skill 及其操作指南，按照指南一步步带我操作。
编写或修改 Lua 前，必须完整读取 Skill 内的 references/AI编码必读.md。
我已经进入一个空测试关卡，还没有创建模板或结算节点图。
每次告诉我当前步骤的入口、动作、完成标志和下一步。
需要模板索引时，我会从编辑器复制给你。
代码交付为本地完整 Lua 文件，由我打开编辑器生成的脚本文件粘贴保存。
```

如果已经搭好测试环境，把“空测试关卡”一句改为真实进度，并提供已有索引；不要为了测试让 AI 假定环境为空。

### 2. 按结果判断是否通过

| 检查项 | 通过标准 |
|---|---|
| Skill 加载 | AI 实际读取 `SKILL.md` 和操作指南；编写或修改 Lua 前完整读取 `references/AI编码必读.md`，按对应规则工作 |
| 操作指导 | 能跟着界面完成每一步；不编造入口，不要求修改无法改名的子控件；GameRoot 使用别名 |
| 信息收集 | 按进度索取真实模板根索引和必要信息，不猜 ID、不要求整套无关配置 |
| Lua 交付 | 提供完整代码，说明接口依据和已做的检查；明确哪些仍待实机验证 |
| 两处挂载 | 明确指导将客户端脚本挂在 GameRoot，并把服务端结算节点图添加到玩家模板 |
| 基础游戏 | 显示和操作正常；没有官方动效资源时，游戏与代码动画也能运行 |
| 重开与失败 | 连续重开三次无明显重复响应；失败和重开不触发成功结算 |
| 运动与性能（适用时） | 短按和松手响应及时，移动与镜头没有明显跳变；特效密集、暂停恢复和连续重开后表现正常；分别说明本地模拟与实机观察结果 |
| 官方成功结算 | 通关后完成游玩，出现官方成功结算；不能只停在自绘通关画面或收到信号回执 |
| 问题修复 | 遇到错误时根据实际证据定位，给出具体修复动作，不反复要求执行无效步骤 |

结构校验通过只能说明 Skill 文件格式符合要求，不能代替这次从新对话到实机结算的完整试用。

### 3. 再验证复用与可选功能

基础流程走通后，备份测试关卡和代码，再按需要测试：

- **换玩法：**在同一套模板和挂载环境下，要求生成另一种简单游戏；检查 AI 能否沿用配置，只列出真正需要变更的操作。
- **概念图还原：**先确定概念图，检查 AI 是否拆解构图与素材，并在实现后对照实际截图调整；检查是否擅自改成像素风，以及实际尺寸下的轮廓、文字和运动是否清晰平滑。确认复杂细节的简化或新增素材需求已说明，没有把概念图或本地预览宣称为实机效果。
- **单个动效：**添加一个官方界面动效，检查脚本能否自动找到并触发；声音需选用带声资源并开启音效。
- **多个动效：**按指南提供用途顺序，检查不同事件是否播放对应动效，重开后是否正常。
- **故障排查：**遇到节点图错误时，提供完整报错和导出的 `.gia`；检查 AI 是否说明实际读到的内容，不把缺失信息当作工程配置错误。

另外可以在另一个新对话中不写 Skill 名称，直接说“帮我在原神千星奇域从零做一个二维 UI 小游戏”，检查是否会自动选中这个 Skill。自动触发与具体客户端的技能发现机制有关，明确指定名称的试用应先通过。[官方 Skill 测试建议](https://developers.openai.com/plugins/build/skills#test-the-skill)

试用卡住时，记录当前步骤、AI 原话、完整报错或相关截图，以及实际有效的修复方法。将问题反馈到维护仓库，修订对应说明后再验证；无需整理整段聊天。

## 别人如何下载和安装

当前仓库为私有：拥有仓库读取权限的人可以按以下方式安装试用。其他人暂时无法访问或下载；公开后可继续使用同一个地址安装。

通过安装器访问私有仓库时，需要在运行 Codex 的环境中完成 GitHub 身份验证，并使用有读取权限的账号；手动下载 ZIP 时，也需要在浏览器中登录有权限的账号。

### 方式一：让 Codex 安装

把下面内容发给 Codex：

```text
使用 $skill-installer，从下面的 GitHub 仓库安装 Skill：
https://github.com/chen-985211/genshin-qianxing-2d-game

SKILL.md 位于仓库根目录，仓库内路径为 .
使用 main 分支。
安装名称请使用 genshin-qianxing-2d-game。
请同时保留 references 和 agents 目录。
```

本仓库的 Skill 位于根目录，使用安装脚本时应指定 `--path . --name genshin-qianxing-2d-game`。安装后开启新对话，发送上面的试用提示即可。若未识别到新 Skill，再重启 Codex 检查。Codex 官方支持通过 `$skill-installer` 从其他仓库安装，适合本阶段的本地试用。[官方安装说明](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)

### 方式二：下载 ZIP 后手动安装

1. 打开[仓库页面](https://github.com/chen-985211/genshin-qianxing-2d-game)，下载 `main` 分支的 ZIP 并解压。
2. 找到直接包含 `SKILL.md` 的目录，将该目录命名为 `genshin-qianxing-2d-game`。完整保留其 `references` 和 `agents` 子目录，不能只复制 `SKILL.md`。
3. 按当前 Codex 文档，将整个目录放入用户级 `~/.agents/skills/`；Windows 对应用户主目录下的 `.agents/skills/`。如果安装器已经装过，沿用已有位置，避免在不同位置重复安装同名 Skill。
4. 确认路径为 `~/.agents/skills/genshin-qianxing-2d-game/SKILL.md`，没有多套一层解压目录。
5. 开启新对话并指定 `$genshin-qianxing-2d-game` 试用。

当前官方文档使用 `.agents/skills` 作为本地发现路径；部分安装器和已有环境使用 `$CODEX_HOME/skills`（默认 `~/.codex/skills`）。安装器方式交由安装器选择位置，手动安装按当前文档操作；作者现有安装已经被识别，无需迁移。[官方本地 Skill 路径说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)
